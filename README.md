Aprender a **detectar, investigar, responder y documentar** incidentes de seguridad con criterios de un analista SOC. Este repositorio es un diario de aprendizaje y portafolio; **no es una copia del curso oficial**.

## Ética, seguridad y publicación
Toda simulación ofensiva se hará **solo en entornos propios o autorizados**. No subir credenciales, tokens, IP privadas sensibles, dumps con datos personales ni capturas sin anonimizar. Las evidencias se presentarán como resultados reales únicamente después de haberlas obtenido.
